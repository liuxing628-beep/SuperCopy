SuperCopy now has a native macOS edition. This release includes both Windows and Mac downloads built from the same tagged source revision.

- **macOS**: universal app for Apple silicon and Intel; requires macOS 13 or later. Open `SuperCopy.app`, grant Accessibility in its settings, then record a capture shortcut and a panel shortcut or mouse button. The clipboard icon in the menu bar opens Settings.
- **Windows**: the established Windows 10/11, .NET Framework 4.8 app.
- Both editions preserve natural tab/line-break order and add the newest capture at the front. They support click to paste, right-click to remove, drag to reorder, and holding a dragged block over another block to merge.
- The Mac app is ad hoc signed and has not been notarized by Apple. First launch may require the per-app **Open Anyway** option. [Apple's instructions](https://support.apple.com/en-us/102445)

The release workflow runs Windows tests, Mac core and AppKit smoke checks, and an Intel Mac launch test. Accessibility-mediated copy and paste in external applications requires a real desktop session with user-granted permissions.
